# Purpose of this project
This project was a Boot.dev course about building a fileserver in Go.

## Things Accomplished and Learned In This Course
- Built an HTTP server from scratch in Go.
- Built a local Postgres database.
- Built Restful APIs that performed CRUD operations on a Postgres database.
- Learned Goose to create and perform Postgres database migrations from SQL commands.
- Used SQLC to generate Go code to perform SQL qureries. 
- Used JWTs to perform authentication across API requests.
- Added authorization logic to keep users from updating other users data.
- Built a webhook that would only work with the use of an API key from a third party.
- Used Jujutsu version control system for remote and local repository maintenance.
